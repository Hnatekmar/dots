# Pinned SHA256 digests for release assets whose upstream publishes no usable
# checksum file (or none at all). Format is sha256sum-compatible:
#
#   <sha256>  <filename>
#
# Installers look up by filename, which carries the tool, version and
# architecture, so entries for several versions can coexist. Add or refresh one
# with:
#
#   scripts/add-checksum.sh <release-asset-url>
#
# Nothing here is fetched at install time, deliberately: the GitHub API allows
# 60 anonymous requests per hour per IP, which a fleet of dev containers
# exhausts, and a digest committed to the repo is a stronger guarantee than one
# fetched at install time.
